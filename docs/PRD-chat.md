# 产品需求文档（PRD）— DocGraph 对话界面（Chat）

> 一句话：在 DocGraph 的知识图谱上提供**自然语言对话入口**——既能**问答你的文档**（基于图谱与原文证据），也能**用对话驱动图谱探索**（"帮我聚焦到 XX 的关联"）。

## 1. 产品概述

### 1.1 背景与问题

图谱帮用户**看清结构**，但仍有门槛：
- 用户想了解某个主题的来龙去脉，需要手动点节点、看证据、拼信息；
- 用户的疑问是**自然语言**（"这份文档里提到了哪些方法？它们的演化关系？"），难以在图上直接检索；
- 已有图谱工具只"展示"，不"对话"。

### 1.2 价值主张

| 价值 | 说明 |
|---|---|
| 问答 | 用自然语言提问，答案**基于你的文档与图谱**，并给出**原文依据**（可跳转定位） |
| 对话式探索 | 用指令驱动图谱："聚焦到 X""展示 X 与 Y 的关系路径""只看方法类实体" |
| 可信 | 每个结论附出处（文档+页码+原文摘录），避免 LLM 幻觉 |
| 联动 | 点回答中提到的实体 -> 图谱高亮定位，回答与图双向联动 |

### 1.3 定位

对话界面是图谱的**自然语言交互层**：图谱是"地图"，对话是"导游/搜索框"。

---

## 2. 目标用户与使用场景

- 沿用主 PRD 学术/研究场景。
- **场景 A（文档问答）**：用户导入一批论文 -> 问"这些方法都改进了什么？" -> 得到带依据的归纳回答。
- **场景 B（图谱探索）**：用户问"GNN 和 Transformer 是什么关系？" -> 对话给出关系+证据，并在图上高亮两者路径。
- **场景 C（筛选/聚焦）**：用户说"只看人物实体" -> 对话触发图谱筛选。

## 3. 功能需求

> 优先级：**P0** = MVP，**P1** = V1.1，**P2** = V2.0。
> 均复用主 PRD 的实体类型表 / 关系类型表 / 证据体系（FR-302/303/307）。

### 3.1 对话入口与布局

**FR-C01 对话面板（P0）**
- 描述：主界面右侧或底部提供对话面板；顶部主图谱与对话可并排/切换。
- 验收：对话面板常驻可用；与图谱联动状态可见（回答中实体点击 -> 图谱高亮）。

**FR-C02 会话管理（P1）**
- 描述：会话（conversation）持久化，可新建/切换/删除；多轮上下文保留；会话与项目绑定。
- 验收：重启后会话可恢复；切换项目会话隔离。

### 3.2 知识库问答（RAG）

**FR-C11 文档/图谱问答（P0）**
- 描述：用户提问 -> 系统从**图谱+文档分块**召回相关证据 -> LLM 生成带引用的回答。
- 验收：答案至少包含 1 条可点击的证据引用（出处+原文），无证据时明确说明"未在文档中找到依据"。

**FR-C12 图谱知识问答（P0）**
- 描述：回答可引用**图谱结构与实体属性**（如"GNN 是 概念/方法/理论，被 GAT 改进"）。
- 验收：涉及图谱实体的问题能返回实体类型/关系/置信度信息。

**FR-C13 引用与定位（P0）**
- 描述：回答中实体/依据可点击 -> 图谱高亮该实体、右侧详情显示证据、文档定位到页码（复用 FR-307/505）。
- 验收：点击引用跳转正确，路径/实体高亮正确。

### 3.3 图谱对话式探索

**FR-C21 自然语言->图谱操作（P1）**
- 描述：LLM 通过工具调用（tool calling）把用户意图转成图谱操作：
  - 聚焦实体（focus）、展开邻居（expand）、
  - 筛选类型（filter by type）、最短路径（path between A、B）、
  - 只看某文档子图、显示统计。
- 验收：常见意图能被正确识别并执行；执行前展示"我将执行：…"确认（可关闭自动执行）。

**FR-C22 意图可解释（P1）**
- 描述：对话展示它理解的意图与将执行的图谱操作，用户可确认/取消。
- 验收：误识别时用户可取消，不直接改视图。

### 3.4 回答质量与上下文

**FR-C31 多轮上下文（P0）**
- 描述：对话保留上下文（会话内），支持"那它呢？""再详细点"等指代。
- 验收：连续多轮问答指代解析正确。

**FR-C32 来源置信（P0）**
- 描述：回答标注所用依据（每条证据带来源文档+页码+quote+置信度）；低置信答案给出提醒。
- 验收：答案中对每个关键论断能对应到证据条目。

### 3.5 系统提示与技术约束

**FR-C41 角色与知识边界（P0）**
- 描述：对话应聚焦于**本项目文档/图谱**；超出知识范围的提问应说明"仅基于你的文档"，不答与文档无关内容。
- 验收：回答不臆造文档外的"事实"；被问无关问题时给出边界说明。

**FR-C42 对话与抽取共用 Key（P0）**
- 描述：复用已配置的 LLM API 配置（FR-801/802），无需重复配置。
- 验收：使用已存 Key；无 Key 时引导配置。

## 4. 非功能需求

| 类别 | 需求 | 指标 |
|---|---|---|
| 性能-问答 | 单轮首 token 延迟 | <= 3s（并发 1，取决于 LLM） |
| 性能-检索 | 证据召回 | 100 文档规模 <= 1.5s |
| 可靠性 | 回答出错/超时 | 明确报错并可重试；不阻塞图谱操作 |
| 隐私 | 发送内容 | 仅发送检索到的分块+图谱相关数据；设置页可预览 |
| 成本 | 可控 | 对话与抽取共用预算提示；可配最大上下文轮数 |
| 可解释 | 证据溯源 | 每个关键论断可溯源到原文（FR-C32） |

## 5. 技术方案建议

### 5.1 总体流程（RAG + Graph 工具增强）

用户提问
  -> [检索] 1) 向量/关键词检索相关文档分块  2) 解析用户提及的图谱实体
  -> [组装] 系统提示(角色/知识边界) + 检索引证(分块+实体/关系/证据)
  -> [LLM] 对话完成 -> 生成带引用答案  (可选: 图谱操作工具调用)
  -> [展示] 答案 + 证据引用 + 图谱联动(高亮/定位)

### 5.2 关键组件

| 组件 | 方案 |
|---|---|
| 检索 | 分块向量检索（本地轻量 embedding，可选 LLM embedding）+ 关键词/图谱实体匹配；读主 PRD 的 chunk/entity 存储 |
| 图谱工具 | 定义图谱操作 schema（focus/expand/filter/path/stats），经 OpenAI 兼容 **function calling** 执行并回填 |
| 对话 | 会话历史（SQLite 或内存 + 持久化）；上下文轮数上限可配 |
| Provider | 复用 `OpenAICompatibleExtractor` 同族（chat.completions 接口），加 `tools` 参数 |
| 引用 | 复用 FR-307 的证据结构（evidence/quote/document/page）；前端可点击跳转 |

### 5.3 数据结构（新增，基于主 PRD 7.3）

- `conversation(id, project_id, title, created_at)`
- `message(id, conversation_id, role, content, created_at)`
- `message_citation(message_id, evidence_json)` —— 消息对证据条目的引用

### 5.4 新增接口

- `POST /api/projects/{pid}/conversations`（新建会话）
- `GET  /api/projects/{pid}/conversations`
- `POST /api/projects/{pid}/chat`（{conversation_id, message} -> {answer, citations}）
- `POST /api/projects/{pid}/graph/command`（图谱对话操作，可选在 chat 内闭环）
- `GET  /api/projects/{pid}/conversations/{cid}/messages`

## 6. 数据与隐私

- 仅发送被检索到的相关分块 + 图谱数据（未发送整库）；设置页可预览"将发送的数据"。
- 会话与引用本地持久化；Key 复用安全存储。
- 支持关闭对话功能（仅查看图谱）。

## 8. 验收标准（示例）

- 导入含「GNN / GAT」的文档并抽取后，问"GNN 和 GAT 是什么关系？" -> 回答含关系与依据（引用原文）；点击引用 -> 图谱高亮对应节点与详情。
- 问"这些文档提到哪些方法？" -> 按实体类型归纳，每条含出处。
- 问"太阳有多大？" -> 说明"仅基于你的文档，未找到相关依据"。
- 无 Key 时给引导；配置后免重复配置即可对话。

## 9. 待决问题（Open Questions）

| # | 问题 | 建议 |
|---|---|---|
| 1 | 对话与图谱是否同屏（右栏对话 vs 底部抽屉） | 建议右栏可切换「详情 / 对话」标签，保持画布可见 |
| 2 | 检索用向量还是关键词 | 建议本地轻量 embedding + 关键词兜底，降低依赖 |
| 3 | 图谱操作是否需用户确认 | 建议执行前展示意图并确认（FR-C22），V1.3 可改"自动执行+可撤销" |
| 4 | 会话存储位置 | 与项目同库（conversation/message 表），随项目备份 |
| 5 | 对话成本上限 | 建议会话最大消息轮数 + 单次预算提示 |
